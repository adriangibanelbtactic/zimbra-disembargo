# Zimbra 10.1.11 source-extractor review

Reviewed 2026-10-16 for the `10.1.10` to `10.1.11` release umbrella. Debian
build IDs below identify package artifacts only; they are not upstream tags.

## Security-fix decisions

The [10.1.11 release announcement](https://wiki.zimbra.com/wiki/Zimbra_Releases/10.1.11#Security_Fixes_in_10.1.10)
has a section headed “Security Fixes in 10.1.10”. It lists the five prior-release
items below (without CVE IDs or CVSS values), rather than a new 10.1.11 security
fix. The only 10.1.11 fixed issue described above that section is an ActiveSync
mail-reply issue. Every listed security item is **not created**: no 10.1.11
target-selected upstream repository has a public target tag, and no non-patch
Debian package build begins with `10.1.11` in any supported Ubuntu catalogue.

| Security fix | Result | Evidence boundary |
| --- | --- | --- |
| GraphiQL IDE disabled at `/modern/graphiql` | **Not created** | No selected repository has `10.1.11`, including `zm-gql`; there is no target-tag source scope/baseline. There is also no non-patch `10.1.11` package pair. |
| `@babel/runtime` 7.27.6 ReDoS upgrade | **Not created** | The announcement does not name an upstream source path. No target-tag source scope or non-patch `10.1.11` package pair establishes a text artifact. |
| ResetPasswordRequest SOAP CSRF token validation | **Not created** | No target-tag source scope or non-patch `10.1.11` package pair. A source path was not inferred from the security description. |
| Auth token required for 2FA modifications | **Not created** | No target-tag source scope or non-patch `10.1.11` package pair. A source path was not inferred from the security description. |
| Rsync 3.4.1 upgrade | **Not created** | No target-tag source scope or non-patch `10.1.11` package pair; the release page lists the target package only as `zimbra-patch`, which is excluded from this non-patch workflow. |

The `10.1.10` review records the earlier package-backed boundaries for these
announcement items. This review does not carry those package comparisons forward
as evidence of a `10.1.11` source change.

## Non-patch package comparison and extractor run

The fixed-name analysis container was stopped before package work. The launcher
was then run sequentially to start the environment and catalogue all supported
Ubuntu series:

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis stop
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis start
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis catalog-availability
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 zm-web-client 10.1.10 10.1.11
```

`ubuntu-repository-version-map.json` contains 24 occurrences of `10.1.10` and
none of `10.1.11`; this is true across Ubuntu 18, 20, 22, and 24. The release
announcement likewise declares only `zimbra-patch` version
`10.1.11.1754392129-2`. Patch packages are excluded from the catalogue, so
there is no non-patch package build pair, no package artifact hunk, and no
candidate changed or removed text artifact.

The actual existing-extractor invocation failed during package selection with:

```text
error: No catalogued zimbra-mbox-webclient-war build begins with release 10.1.11
```

Consequently it generated no comparison directory, `manifest.json`, matched or
unmatched hunk report, reconstructed `upstream.diff`, or comparison role. There
are no exact Debian before/after pairs to record, including no
`release-baseline` or `immediate-predecessor` result, and no removal that could
produce a `deleted file mode` source diff. This is an unavailable-package
boundary, not an upstream-only validation.

## Extractor changes

a unique exact before-side source match is empty for this release umbrella.
