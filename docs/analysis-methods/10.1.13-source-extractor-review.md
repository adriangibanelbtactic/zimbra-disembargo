# 10.1.13 source-extractor review

Reviewed `10.1.12` → `10.1.13` on 2026-10-16.  Two existing extractor
definitions were extended for installed, non-patch Debian text artifacts:
`zm-admin-console` for the RestFilter removal and `zm-web-client` for the PDF
preview removal.  No definition was created: each upstream GitHub repository
continues to have exactly one definition.

## Extractor definitions extended

- `source-extractors/zm-admin-console.json`: scopes the direct installed
  `opt/zimbra/jetty_base/webapps/zimbraAdmin/WEB-INF/web.xml` artifact and maps
  it to XML candidates under `WebRoot/WEB-INF`.
- `source-extractors/zm-web-client.json`: scopes direct installed
  `ZmMimeTable.js` and `ZmMailMsgView.js` artifacts and maps each to its
  explicit source directory.

Both mappings use exact before-side matching; the resulting source paths are
not inferred from announcement text.  Generated package payloads, survey data,
and extractor results remain under ignored `cache/` and `var/` paths.
