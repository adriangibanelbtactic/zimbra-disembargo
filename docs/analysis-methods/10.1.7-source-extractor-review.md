# Zimbra 10.1.6 to 10.1.7 source-extractor review

This review compares the public component tags `10.1.6` and `10.1.7` with the
non-patch Debian package workflow.  It accepts shipped text artifacts such as
shell, JavaScript, JSP, template, and XML files; Java source and JAR payloads
are outside the extractor scope.

## Repository survey boundary

`zm-build` has no public `10.1.7` tag.  The repository selection therefore
uses its preceding `10.1.6` tag, as reported by
`zm-build-print-repos.pl`.  Of the 53 selected repositories, only two expose
both component tags:

| Repository | Changed public material | Result |
| --- | --- | --- |
| `zm-core-utils` | `src/bin/zmlicensectl` (Bash). | **Created: `zm-core-utils`.** The proxy-timeout command and LDS launch-time timeout are textual source changes. |
| `zm-mailbox` | `store/conf/attrs/zimbra-attrs.xml` plus 34 Java implementation/test/API files. | **Not created.** The XML is a text change, but it moved into the new `zimbra-common-mbox-conf-attrs` package at 10.1.7; there is no same-package 10.1.6 artifact for this single-package extractor. All other changed sources are Java and ship in JARs. |

The remaining 51 selected repositories lack at least one component tag.  No
conclusion about a source change can be drawn from their missing tag pair.

## `zm-core-utils` extractor

[`zm-core-utils.json`](../../source-extractors/zm-core-utils.json) maps the
textual installer artifact `opt/zimbra/bin/zmlicensectl` in `zimbra-core` to
`src/bin/zmlicensectl` in `Zimbra/zm-core-utils`.  The mapping is scoped to the
one executable and reconstructs all four 10.1.6-to-10.1.7 source hunks with no
unmatched hunk.

Current Ubuntu 18, 20, and 22 APT metadata retain no `zimbra-core` package
build for 10.1.7, and the checked-in local-installer manifests currently cover
only 10.1.0.  Accordingly, this mapping was **synthetically validated** from
the public `10.1.6` and `10.1.7` source text; it is not a Network Edition
package extraction.  Add verified 10.1.6 and 10.1.7 installer manifests, then
use the documented `--local-release` workflow to produce the package-backed
result.

The resulting text implements the 10.1.7 Licensing fixed issue that increases
the License Proxy Service timeout and adds `getProxyTimeout` and
`setProxyTimeout` support to `zmlicensectl`.
