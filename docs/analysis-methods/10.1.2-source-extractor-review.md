# Zimbra 10.1.2 text source-extractor review

This review compares public Zimbra component tags `10.1.1` and `10.1.2`, then
requires the changed source to be represented by a changed, non-binary Debian
package artifact before adding an extractor.

## Repository selection

`Zimbra/zm-build` has no `10.1.2` tag.  The repository survey consequently
uses its nearest preceding build tag, `10.1.1`, to invoke
`zm-build-print-repos.pl`; it still checks component tags `10.1.1` and
`10.1.2` in every selected repository.  Of the 53 selected repositories, only
these expose both component tags:

```text
zm-admin-console
zm-core-utils
zm-mailbox
```

## Results

| Repository | Public text change | Package evidence | Extractor result |
| --- | --- | --- | --- |
| `zm-admin-console` | Five `ZaMsg_*.properties` Storage Management translation corrections | The same five text artifacts change in `zimbra-mbox-admin-console-war` from `10.1.1.1723652473-1.u18` to `10.1.2.1725893697-1.u18`. | **Created/extended: `zm-admin-console`**. All five package hunks map uniquely to their matching source files. |
| `zm-core-utils` | Shell changes to `zmlicensectl` and a new installer script | `zimbra-license-tools` changes only `zimbra-license-tools.jar` for the corresponding package pair. | **Not created**. The package payload is a JAR, not a text artifact. |
| `zm-mailbox` | `GetDomainInfo.java` | The corresponding common-core package changes JARs. | **Not created**. Java/JAR content is outside text-hunk extraction. |

The 10.1.2 GraphQL CSRF announcement is therefore not represented by a new
text source extractor: no tag-paired, package-backed textual artifact was
identified for it.

## Reproduce the supported extraction

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 --local-release 10.1.0 \
  zm-admin-console 10.1.1 10.1.2
```

The output contains five exact mappings and no unmatched hunk.  It scopes the
extractor to the five installed `.properties` files, excluding the 20 other
changed package artifacts from this focused source extraction.
