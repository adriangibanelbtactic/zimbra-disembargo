# Zimbra 10.1.2 text source-extractor review

This review compares public Zimbra component tags `10.1.1` and `10.1.2`, then
requires the changed source to be represented by a changed, non-binary Debian
package artifact before adding an extractor.

## Repository selection

`Zimbra/zm-build` has no `10.1.2` tag. The repository-selection helper uses
its nearest preceding build tag, `10.1.1`, to obtain the 53 target repository
URLs. The survey requires only the target component tag, then selects the
nearest lower component tag in each repository. Four repositories expose
`10.1.2` and a usable baseline:

| Repository | Target tag | Selected baseline |
| --- | --- | --- |
| `zm-admin-console` | `10.1.2` | `10.1.1` |
| `zm-core-utils` | `10.1.2` | `10.1.1` |
| `zm-gql` | `10.1.2` | `10.1.0` (no `10.1.1` tag) |
| `zm-mailbox` | `10.1.2` | `10.1.1` |

## Results

| Repository | Public text change | Package evidence | Extractor result |
| --- | --- | --- | --- |
| `zm-admin-console` | Five `ZaMsg_*.properties` Storage Management translation corrections | The same five text artifacts change in `zimbra-mbox-admin-console-war` from `10.1.1.1723652473-1.u18` to `10.1.2.1725893697-1.u18`. | **Not created/extended**. Translation-only changes are deliberately outside CVE and security-relevant extractor scope. |
| `zm-core-utils` | Shell changes to `zmlicensectl` and a new chat/video installer script | `zimbra-license-tools` changes only `zimbra-license-tools.jar` for the corresponding package pair. The existing `zm-core-utils` extractor maps `zimbra-core`, for which no 10.1.1/10.1.2 package pair is available. | **Not extended**. The available package payload is a JAR, not a text artifact. |
| `zm-gql` | `GQLServlet.java` disables GraphQL GET by default behind the new localconfig key. This is the public implementation of CVE-2024-9665. | `zimbra-common-core-jar` changes five JARs (`zimbra-native`, `zimbraclient`, `zimbracommon`, `zimbrasoap`, and `zimbrastore`) between `10.1.1.1724061993-1.u18` and `10.1.2.1725992150-1.u18`. | **Not created**. The only source change is Java and the installed implementation is JAR-only. |
| `zm-mailbox` | `GetDomainInfo.java` | The corresponding common-core package changes JARs. | **Not created**. Java/JAR content is outside text-hunk extraction. |

The 10.1.2 GraphQL CSRF announcement is therefore not represented by a new
text source extractor: its public source and installed implementation are Java
and JAR material, respectively.

No 10.1.1 → 10.1.2 text source extractor was added.  The existing
`zm-admin-console` definition intentionally scopes itself to its security- and
feature-relevant JavaScript bundle, excluding `ZaMsg*properties` and
`ZsMsg*properties` translation artifacts.
