# Zimbra 10.1.5 to 10.1.6 source-extractor review

This review compares public Zimbra component tags `10.1.5` and `10.1.6` and
requires a changed, non-binary Debian package artifact before extending an
extractor. Java source files and JAR payloads are out of scope. Translation-only
message resources are also deliberately excluded from source extractors.

## Repository survey boundary

`zm-build-print-repos.pl` selects the same 53 repositories for both release
labels. Only two selected repositories expose both component tags:

| Repository | Changed public material | Result |
| --- | --- | --- |
| `zm-mailbox` | Nine Java implementation/test files, including `FileUploadServlet`, `ModifyAccount`, `ModifyCos`, `NativeFormatter`, and `ParseMimeMessage`. | **Not created.** Java source is outside scope and the Ubuntu 22 `zimbra-common-core-jar` pair changes five JARs (`zimbra-native`, `zimbraclient`, `zimbracommon`, `zimbrasoap`, and `zimbrastore`). |
| `zm-web-client` | Thirteen `ZhMsg*`, `ZmMsg*`, and `ZtMsg*` message-resource files: copyright-year updates plus restoration of Bulgarian `ZmMsg`. | **Not extended.** The corresponding `zimbra-mbox-webclient-war` artifacts are translation/copyright resources, not security- or feature-relevant source. The new Bulgarian file also has no common before-side artifact hunk. |

The other 51 selected repositories lack one or both component tags, so an
absent public diff cannot be inferred for them.

## Package evidence

The retained Ubuntu 22 packages make both comparisons reproducible without a
local installer source:

```text
zimbra-mbox-webclient-war  10.1.5.1737655177-1.u22 -> 10.1.6.1738908936-1.u22
zimbra-common-core-jar     10.1.5.1737379628-1.u22 -> 10.1.6.1738737738-1.u22
```

The web-client comparison has 177 changed common artifacts, including the
changed message resources, generated Java/JSP output, bundles, JARs, and
images. None supplies a new eligible text artifact for the existing
`zm-web-client` extractor. Consequently no 10.1.5 to 10.1.6 source extractor
definition or mapping is added.
