# Zimbra 10.1.3 text source-extractor review

This review compares public Zimbra component tags `10.1.2` and `10.1.3`, then
requires a changed, non-binary Debian package artifact before adding an
extractor. Java source files and JAR payloads are outside this review's scope.

## Repository selection

`Zimbra/zm-build` has neither requested tag. The repository survey consequently
uses its nearest preceding build tag, `10.1.1`, to invoke
`zm-build-print-repos.pl`, then checks the requested component tags in all 53
selected repositories. Only these repositories expose both component tags:

```text
zm-core-utils
zm-mailbox
```

Repositories such as `zm-web-client`, `zm-ajax`, and `zm-jetty-conf` expose
`10.1.3` but not `10.1.2`; no missing-side source diff is inferred from that
fact.

No 10.1.2 → 10.1.3 source extractor was added.
