# Zimbra 10.1.3 text source-extractor review

This review selects repositories from the target 10.1.3 `zm-build` repository
set, requires only the target component tag, and compares it to each
repository's nearest lower available 10.1.x tag. It then requires a changed,
non-binary Debian package artifact before adding or extending a source
extractor. Java source and JAR payloads are out of scope.

## Repository selection

`Zimbra/zm-build` has no public 10.1.3 tag, so
`zm-build-print-repos.pl` uses the preceding 10.1.1 build tag to obtain the 53
target repository URLs. Five selected repositories expose their own 10.1.3 tag
and a usable lower baseline:

| Repository | Target tag | Selected baseline | Relevant changed material |
| --- | --- | --- | --- |
| `zm-ajax` | `10.1.3` | `10.1.1` | `DwtIframe.js`, `AjxStringUtil.js` |
| `zm-core-utils` | `10.1.3` | `10.1.2` | `zmcontrol` Perl script |
| `zm-jetty-conf` | `10.1.3` | `10.1.0` | `webdefault.xml` and production variant |
| `zm-mailbox` | `10.1.3` | `10.1.2` | Java plus `ZsMsg*.properties` message resources |
| `zm-web-client` | `10.1.3` | `10.1.1` | `/h/rest` `.tag` files and `Resources.jsp` |

`zm-ajax` and `zm-web-client` do not publish 10.1.2, so their 10.1.1
baselines are intentional fallback results, not missing evidence.

## Validated extractor results

The Ubuntu 18 `zimbra-mbox-webclient-war` package pair
`10.1.1.1723653022-1.u18` to `10.1.3.1728575700-1.u18` provides both
package-backed validations:

| Extractor | Scoped installed artifact | Reconstructed source | Exact hunks |
| --- | --- | --- | --- |
| [`zm-web-client`](../../source-extractors/zm-web-client.json) | `WEB-INF/tags/rest/restDocument.tag`, `restDocumentPreview.tag`, `restDocumentView.tag`, and `public/Resources.jsp` | The corresponding four `WebRoot` files | 8 / 8 |
| [`zm-ajax`](../../source-extractors/zm-ajax.json) | `js/Ajax_all.js` | `WebRoot/js/ajax/dwt/widgets/DwtIframe.js` and `WebRoot/js/ajax/util/AjxStringUtil.js` | 4 / 4 |

The `zm-web-client` extension is the package-backed source mapping for
CVE-2024-54663 (LFI) and CVE-2025-27914 (XSS) in `/h/rest`. Its upstream
commit removes unused REST views, gives the generated resource extension a
safe default, and XML-escapes the request version before it is rendered. The
`zm-ajax` result reconstructs the HTML/iframe parsing changes from
ZBUG-4108/ZBUG-4121.

Run either validation explicitly with:

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 <extractor-name> 10.1.1 10.1.3
```
