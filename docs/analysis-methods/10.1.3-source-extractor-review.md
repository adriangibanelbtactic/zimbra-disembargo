# Zimbra 10.1.3 text source-extractor review

This review selects repositories from the target 10.1.3 `zm-build` repository
set, requires only the target component tag, and compares it to each
repository's nearest lower available 10.1.x tag. It then requires a changed,
non-binary Debian package artifact before adding or extending a source
extractor. Java source and JAR payloads are out of scope.

## Repository selection

`Zimbra/zm-build` has no public 10.1.3 tag, so
`zm-build-print-repos.pl` uses the preceding 10.1.1 build tag to obtain the 53
target repository URLs. Five selected repositories expose their own 10.1.3 tag
and a usable lower baseline:

| Repository | Target tag | Selected baseline | Relevant changed material |
| --- | --- | --- | --- |
| `zm-ajax` | `10.1.3` | `10.1.1` | `DwtIframe.js`, `AjxStringUtil.js` |
| `zm-core-utils` | `10.1.3` | `10.1.2` | `zmcontrol` Perl script |
| `zm-jetty-conf` | `10.1.3` | `10.1.0` | `webdefault.xml` and production variant |
| `zm-mailbox` | `10.1.3` | `10.1.2` | Java plus `ZsMsg*.properties` message resources |
| `zm-web-client` | `10.1.3` | `10.1.1` | `/h/rest` `.tag` files and `Resources.jsp` |

`zm-ajax` and `zm-web-client` do not publish 10.1.2, so their 10.1.1
baselines are intentional fallback results, not missing evidence.

## Security-fix decisions

The [10.1.3 release announcement](https://wiki.zimbra.com/wiki/Zimbra_Releases/10.1.3#Security_Fixes)
has five Security Fixes entries.  The results below keep the announcement
boundary separate from the package and public-source evidence; a component
upgrade is not treated as a source-path claim.

| Security fix | Result | Evidence boundary |
| --- | --- | --- |
| CVE-2024-54663: authenticated LFI in `/h/rest` | **extended** `zm-web-client` | The selected `Zimbra/zm-web-client` baseline is 10.1.1. Its ZBUG-4238 change explicitly modifies the REST tags and removes four REST views. The retained Ubuntu 18 WAR package pair reconstructs those paths exactly; see the package-backed result below. |
| CVE-2025-27914: authenticated XSS in `/h/rest` | **extended** `zm-web-client` | The same explicit ZBUG-4238 change XML-escapes `requestScope.version` in the REST tags and changes `public/Resources.jsp`. The same package extraction has a unique exact baseline match for every hunk. |
| CVE-2023-22067: OpenJDK 17.0.12 upgrade | **not created** | `zimbra-openjdk` 17.0.8 → 17.0.12 has 247 before-only and 248 after-only versioned-runtime files; its sole changed common file is `usr/share/doc/zimbra-openjdk/changelog.Debian.gz`. There is no selected Zimbra repository or source scope for this third-party runtime. |
| CVE-2023-38709: Apache 2.4.62 upgrade | **not created** | `zimbra-httpd` 2.4.57 → 2.4.62 changes 939 common files, principally Apache ELF binaries/modules and shipped Apache manual pages. No selected Zimbra repository identifies an upstream source scope for those third-party artifacts. |
| CVE-2024-20328: ClamAV 1.0.6 upgrade | **not created** | `zimbra-clamav` 1.0.1 → 1.0.6 changes 26 common files: ClamAV ELF programs, man pages, and its Debian changelog. No selected Zimbra repository identifies an upstream source scope, and the changed text is documentation rather than a shipped source artifact. |

## Validated extractor results

The requested Ubuntu 18 `zimbra-mbox-webclient-war` 10.1.2 → 10.1.3 pair is
not retained in current APT metadata.  An explicitly labelled run,

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 zm-web-client 10.1.2 10.1.3
```

correctly stops with `No catalogued zimbra-mbox-webclient-war build begins with
release 10.1.2`; it does not substitute a package build.  There is no 10.1.2
installer manifest for the documented `--local-release` workflow.

The retained Ubuntu 18 `zimbra-mbox-webclient-war` package pair
`10.1.1.1723653022-1.u18` to `10.1.3.1728575700-1.u18` provides both
package-backed validations:

| Extractor | Scoped installed artifact | Reconstructed source | Exact hunks |
| --- | --- | --- | --- |
| [`zm-web-client`](../../source-extractors/zm-web-client.json) | The `WEB-INF/tags/rest/` directory, including four removed slide/spreadsheet tags, and `public/Resources.jsp` | The corresponding eight `WebRoot` files | 12 / 12 |
| [`zm-ajax`](../../source-extractors/zm-ajax.json) | `js/Ajax_all.js` | `WebRoot/js/ajax/dwt/widgets/DwtIframe.js` and `WebRoot/js/ajax/util/AjxStringUtil.js` | 4 / 4 |

The `zm-web-client` extension is the package-backed source mapping for
CVE-2024-54663 (LFI) and CVE-2025-27914 (XSS) in `/h/rest`. Its upstream
commit removes four unused REST views (`restSlidePreview.tag`,
`restSlideView.tag`, `restSpreadsheetPreview.tag`, and
`restSpreadsheetView.tag`), gives the generated resource extension a safe
default, and XML-escapes the request version before it is rendered. The
`zm-ajax` result reconstructs the HTML/iframe parsing changes from
ZBUG-4108/ZBUG-4121.

The explicit retained-pair runs inspected both reports. `zm-web-client` has 12
matched hunks and an empty unmatched report; four are removed package files.
Its `upstream.diff` contains `deleted file mode 100644` for each of the four
REST source paths, including `restSlidePreview.tag`, whose source has no final
newline. `zm-ajax` has four matched hunks and an empty unmatched report. These
two runs use the survey-selected 10.1.1 baselines and do not claim that a
10.1.2 package pair was available.

Run either validation explicitly with:

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 <extractor-name> 10.1.1 10.1.3
```

## 10.1.2 → 10.1.3 package evidence

`catalog-availability` was queried for Ubuntu 18, 20, 22, and 24. Ubuntu 18
retains the relevant historical builds and was used for the following exact
adjacent comparisons. `deb-inspect --after` selected the listed immediate
predecessor in each case.

| Package pair | Changed common artifacts | Decision boundary |
| --- | --- | --- |
| `zimbra-common-core-jar` `10.1.2.1725992150-1.u18` → `10.1.3.1728626495-1.u18` | Six files: five JARs and `changelog.Debian.gz` | JAR/class payloads and Debian changelog are excluded. |
| `zimbra-ldap-components` `10.1.2` → `10.1.3` | Only `changelog.Debian.gz` | No installed source artifact. |
| `zimbra-mta-components` `10.1.2` → `10.1.3` | Only `changelog.Debian.gz` | No installed source artifact. |
| `zimbra-openjdk` `17.0.8` → `17.0.12` | Only common change is `changelog.Debian.gz`; versioned runtime trees are removed/added | Third-party runtime; no selected Zimbra upstream scope. |
| `zimbra-httpd` `2.4.57` → `2.4.62` | 939 files: Apache executables/modules plus manual pages | Third-party payload/documentation; no selected Zimbra upstream scope. |
| `zimbra-clamav` `1.0.1` → `1.0.6` | 26 files: ELF programs, man pages, and `changelog.Debian.gz` | Third-party binaries/documentation; no selected Zimbra upstream scope. |
