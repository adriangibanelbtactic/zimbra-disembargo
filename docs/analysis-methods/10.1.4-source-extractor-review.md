# Zimbra 10.1.3 to 10.1.4 source-extractor review

This review uses the target release announcement, the target `zm-build`
repository selection, and retained Ubuntu Network Edition packages. A source
extractor is retained or extended only for an installed text artifact whose
before-side hunk has a unique exact match in the selected public baseline.
Java source, JARs/classes, generated payloads, and translated message resources
are excluded.

target `zm-build` configuration. `tag-status.tsv` records target-component tags
and the nearest available lower baseline; a missing 10.1.3 component tag was
not itself a rejection. Ten selected repositories expose 10.1.4 and a baseline:

for every source interpretation.

## Security-fix decisions

The [10.1.4 announcement](https://wiki.zimbra.com/wiki/Zimbra_Releases/10.1.4#Security_Fixes)
has seven Security Fixes rows. “Extended” below identifies an existing
single-repository definition whose scoped package artifact was re-run against
the exact release labels; it does not create a duplicate definition.

| Security fix | Result | Evidence boundary |
| --- | --- | --- |
| Encoded `@import` statements in `<style>` tags (no CVE) | **extended** `zm-ajax` | The exact `Ajax_all.js` package hunk uniquely maps to `zm-ajax` `WebRoot/js/ajax/util/AjxStringUtil.js` (1/1; no unmatched hunks). The primary AntiSamy decoding implementation is Java and remains excluded. |
| CVE-2025-32354: GraphQL CSRF | **not created** | `zm-gql` changes only `GQLServlet.java` and `GQLAuthUtilities.java`; no shipped non-JAR text artifact or existing package mapping identifies a deterministic source candidate. |
| CVE-2025-25065: RSS-parser SSRF | **not created** | The plausible `zm-mailbox` source is `FeedManager.java`; the retained common-core package change is JAR payload only. No source path is inferred from the CVE description. |
| CVE-2025-25064: ZimbraSyncService SQL injection | **not created** | No selected source change supplies a shipped text artifact for this endpoint. The related `zm-mailbox` implementation is Java and the package evidence is JAR-only. |
| CVE-2024-45516: Classic UI crafted-HTML XSS | **not created** | The announced sanitizer change is represented by `zm-mailbox` Java (`HtmlDefang`/OWASP classes) in changed JARs. The co-released `ZmComposeView.js` hunk is reconstructed below but its upstream log is the unrelated ZBUG-4484, so it is not attributed to this CVE. |
| CVE-2025-48700: Classic UI crafted-HTML XSS | **not created** | Same boundary as CVE-2024-45516: the implementation is Java/JAR payload, not an installed text source artifact. |
| ChangePassword API requires an auth token (no CVE) | **extended** `zm-web-client` | The explicit change-password commits alter the installed `h/changepass` text artifact. It uniquely maps to `Zimbra/zm-web-client` at 10.1.3 (4/4 scoped hunks; no unmatched hunks). Backend and tag-library Java changes remain excluded. |

## Package-backed extractor runs

Ubuntu 18 retains the exact `zimbra-mbox-webclient-war` package pair:
`10.1.3.1728575700-1.u18` → `10.1.4.1732702939-1.u18`. Both commands used
explicit release labels:

```sh
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 zm-web-client 10.1.3 10.1.4
scripts/ubuntu24-debian-non-patch-packages-pseudo-code-analysis source-extract \
  --ubuntu-series 18 zm-ajax 10.1.3 10.1.4
```

| Extractor | Scoped installed artifact(s) | Reconstructed public source | Report result |
| --- | --- | --- | --- |
| [`zm-web-client`](../../source-extractors/zm-web-client.json) | `h/changepass`, `public/login.jsp`, `js/Mail_all.js` | `WebRoot/h/changepass`, `WebRoot/public/login.jsp`, `WebRoot/js/zimbraMail/mail/view/ZmComposeView.js` | 4 exact matches; empty unmatched report. |
| [`zm-ajax`](../../source-extractors/zm-ajax.json) | `js/Ajax_all.js` | `WebRoot/js/ajax/util/AjxStringUtil.js` | 1 exact match; empty unmatched report. |

`upstream.diff` for these runs contains no `deleted file mode` entries: there
are no scoped removed text artifacts in this package pair. The existing
`artifact-positive` entries and bundle derivations restrict each extractor to
its explicit installed artifact, so unrelated WAR changes are not presented as
source mappings.

The available `zimbra-mbox-admin-console-war` 10.1.4 build has no catalogued
10.1.3 predecessor in Ubuntu 18 (and the availability map has no retained
10.1.3 build for Ubuntu 20 or 22). The explicit `zm-admin-console 10.1.3
10.1.4` run therefore stops before extraction; its JavaScript changes cannot be
claimed as package-backed validation.
